🎓 CampusCare AI – Smart Campus Issue Management Platform

📌 Project Overview

CampusCare AI is an AI-powered campus issue reporting and management system designed to help universities manage and resolve campus-related problems efficiently.

The platform allows students to report campus issues, upload images, track report progress, and receive AI-powered suggestions. Administrators can manage reports, assign priorities, monitor issues, and improve campus maintenance operations.

By integrating Artificial Intelligence with modern web technologies, CampusCare aims to make campus issue management faster, smarter, and more organized.

🎯 Project Objectives

- Provide an easy and efficient platform for reporting campus issues.
- Improve communication between students and university administrators.
- Use AI to automatically analyze and classify reported issues.
- Identify the priority level of reported problems.
- Reduce duplicate complaints.
- Allow students to track the progress of their reports.
- Provide useful insights through an administrative dashboard.

✨ Key Features

1. Student Features

- Student registration and login.
- Submit campus issue reports.
- Upload photographs related to reported issues.
- Select issue locations and provide descriptions.
- View submitted reports.
- Track report status and updates.
- Receive notifications about report progress.

2. Admin Features

- Secure administrator login.
- View and manage all reported issues.
- Review student complaints.
- Update issue statuses.
- Approve AI-suggested classifications and priorities.
- Manage and monitor pending and resolved reports.
- View campus issue statistics through an admin dashboard.

3. AI-Powered Features

AI Image Recognition

- Analyze uploaded images of campus problems.
- Identify visible maintenance issues.
- Suggest suitable issue categories.

AI Issue Classification

- Analyze submitted issue descriptions.
- Automatically suggest relevant categories such as Electrical, Plumbing, IT Support, and Maintenance.

Intelligent Priority Detection

- Analyze issue descriptions and images.
- Suggest priority levels: Low, Medium, High, and Urgent.
- Provide explanations for suggested priority levels.

CampusCare AI Assistant

- Help students understand how to report campus issues.
- Suggest suitable issue categories.
- Guide students through the reporting process.
- Explain how to track submitted reports.

Duplicate Issue Detection

- Compare newly submitted reports with existing reports.
- Identify potentially repeated complaints.
- Notify students and administrators about possible duplicates.

4. CampusCare Intelligence

- Display total reported issues.
- Show pending and resolved reports.
- Identify frequently reported issue categories.
- Generate AI-powered observations based on actual report data.
- Provide administrators with a summary of campus maintenance issues.

🔄 System Workflow

1. Students log in to the CampusCare platform.
2. Students submit campus issues with descriptions, locations, and images.
3. The AI engine analyzes the submitted information.
4. AI suggests an issue category and priority level.
5. Students review and confirm their reports.
6. Report information is stored in Firebase.
7. Administrators review and manage submitted reports.
8. Administrators update the report status.
9. Students can track the progress of their reports.

📊 Issue Status Management

- Pending – Report has been submitted and is waiting for review.
- Under Review – Administrator is reviewing the issue.
- In Progress – The issue is being handled.
- Resolved – The reported issue has been resolved.
- Rejected – The report has been rejected with a reason.
